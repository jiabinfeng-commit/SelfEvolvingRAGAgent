## 怎么拿到真实的效果数字（替换 README 第九节的"示例"格子）

```bash
# 1) 配好 .env（PG 走隧道 / OPENAI_API_KEY），建表，灌语料
bash scripts/tunnel_pg.sh
python -c "from core.storage.pg_store import PGStore; PGStore().init_schema()"
python scripts/ingest.py            # 阶段1 灌库

# 2) 跑基线评估（纯向量、无自愈），结果落 eval_run 表
python scripts/evaluate.py --limit 50 --note baseline-vector

# 3) 开混合检索再跑
python scripts/evaluate.py --retrieval hybrid --limit 50 --note hybrid

# 4) 开拒答自愈再跑
python scripts/evaluate.py --retrieval hybrid --self-heal --limit 50 --note hybrid+selfheal

# 5) 横向比：直接查 eval_run 表
python -c "from core.storage.pg_store import PGStore; \
pg=PGStore(); [print(r['note'], r['accuracy'], r['recall_top1'], r['refusal_rate']) \
for r in pg.get_traces(0)]"   # 注：eval_run 取数见 core/evaluator 的落库逻辑
```

把第 2/3/4 步的 `accuracy / recall_top1 / refusal_rate` 填进 README 第九节表格，就是真实对比。
